# Malla de Turnos

Proyecto de levantamiento, historias de usuario, backlog y prototipo de diseño del módulo **Malla de Turnos** (integración prevista con GRH).

## Contenido

| Carpeta / archivo | Descripción |
| ----------------- | ----------- |
| `docs/` | HUs GST-FM-04, backlog, plan de BD y documentación funcional |
| `prototipo-figma/` | Prototipo interactivo (React + Vite) para validar diseño y flujos |
| `Propuesta-HU-Malla-Turnos.md` | Propuesta y mapa de historias |
| Excels / levantamientos | Material de operación y fase 1 |

## Prototipo (diseño)

```bash
cd prototipo-figma
npm install
npm run dev
```

Abre http://localhost:5173/

## Nota

Este repositorio concentra el trabajo de producto/diseño de Malla de Turnos. La implementación productivade en el monorepo GRH es un paso posterior.
